# 一問一答 学習合戦

中学生向けの一問一答学習アプリです。戦国合戦をテーマに、問題に答えて敵将を討ち取ります。

## 特徴

- **全5教科996問**（歴史218 / 英語240 / 理科200 / 地理170 / 数学168）
- **全問に解説つき** — 正解・不正解にかかわらず、覚え方や間違えやすい点を丁寧に解説
- **分野を選んで出題** — 定期テストの範囲だけに絞って学習できます
- **復習戦** — 間違えた問題だけを集めて再挑戦
- **戦闘演出** — 解答の速さに応じたダメージ、連撃ボーナス、HPバー
- **ご褒美の絵巻** — 累計正解数に応じて、教科ごとの一枚絵のモザイクが7段階で晴れていきます

## 使い方

ブラウザで `index.html` を開くだけです。ただし問題データを `fetch` で読みこむため、
**ファイルを直接ダブルクリックしても動きません**。ローカルで確認する場合はサーバー経由で開いてください。

```bash
python3 -m http.server
# → http://localhost:8000/index.html
```

## ファイル構成

| ファイル | 内容 |
|---|---|
| `index.html` | アプリ本体（HTML・CSS・JavaScript） |
| `history.json` ほか4件 | 教科ごとの問題データ |
| `boss.png` | 敵武将の立ち絵 |
| `rewards/*.jpg` | 教科ごとのご褒美画像 |

## 問題データの形式

```json
{
  "id": "h001",
  "category": "縄文・弥生",
  "question": "縄文時代の人々が食べ物の残りかすや不要品を捨てた場所を何というか。",
  "answer": "貝塚",
  "explanation": "ただのゴミ捨て場と思いきや、これが最高の宝の山。..."
}
```

- `category` が分野選択のチェックボックスになります（JSONに現れた順に並びます）
- `answer` は小文字化・空白除去した完全一致で判定されます
- 表記ゆれのある語は、設問文で「漢字2字で答えなさい」のように答え方を指定しています

## 調整できる設定

`index.html` の冒頭にある定数を変更すると、難易度やご褒美の条件を調整できます。

```js
const DEFEAT_ACCURACY = 0.9;   // この正答率で敵HPが0になる
const CRITICAL_SEC    = 3.0;   // 会心の一撃（1.2倍）の判定時間
const COMBO_SEC       = 5.0;   // 連撃が続く制限時間。超えると0.7倍
const REWARD_STEPS = [ ... ];  // 絵巻の解像度が上がる正解数
```

## 学習の進み具合

`localStorage` に保存されます。教科ごとに以下の2つを記録します。

- `wrongQuestions_<教科>` — 間違えた問題（復習戦で使用）
- `correctTotal_<教科>` — 累計正解数（絵巻の解像度に使用）

ブラウザのデータを消すと、進み具合もリセットされます。
